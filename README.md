# youngcinemaclub

Закрытый кинокаталог со входом по коду. Администратор может добавлять фильмы в формате MP4 через браузер.

## Запуск на Linux

### 1. Установите Node.js и скачайте проект

- Проверьте версию командой `node --version`. Если команда отсутствует или первое число после `v` меньше 22, установите [Node.js LTS для Linux](https://nodejs.org/en/download). Затем откройте новый терминал и ещё раз проверьте версию.
- На [странице проекта](https://github.com/smifick/website_for_films) нажмите **Code → Download ZIP**. Распакуйте архив и откройте папку `website_for_films-main`.
- Если у вас уже есть копия, скачанная через Git, выполните `git pull` в папке проекта. Если скачивали ZIP, распакуйте свежую копию в отдельную папку и перенесите туда `film-data`, если хотите сохранить фильмы и прежние коды доступа.

### 2. Откройте терминал в папке проекта

В папке должны быть видны `package.json`, `build.mjs` и `server.mjs`.

Откройте папку проекта в файловом менеджере, щёлкните по пустому месту правой кнопкой и выберите **Открыть в терминале**, если есть такой пункт. Или перейдите в папку командой `cd`. Например, если вы распаковали архив в папку `Загрузки`, выполните

```bash
cd ~/Загрузки/website_for_films-main
ls
```

Если папка загрузок называется `Downloads` или архив распакован в другое место, подставьте свой путь. Команда `ls` должна показать `package.json`, `build.mjs` и `server.mjs`. На macOS используются те же команды. В Windows можно открыть папку в Проводнике и ввести `cmd` в адресной строке.

### 3. Соберите и запустите сайт

Выполните команды по очереди. Если первая завершится ошибкой, сначала исправьте её.

```text
node build.mjs
node server.mjs
```

Проект использует встроенные модули Node.js, поэтому установка зависимостей через npm не требуется. При успешной сборке первая команда обычно ничего не выводит. После второй в терминале появится строка `youngcinemaclub: http://localhost:3000`. Оставьте это окно открытым и перейдите в браузере на [http://localhost:3000](http://localhost:3000). Чтобы остановить сервер, нажмите **Ctrl+C**.

### 4. Войдите и добавьте фильм

При запуске на localhost используются следующие данные для входа.

| Куда войти | Что ввести |
| --- | --- |
| [Кинозал](http://localhost:3000/) | Код `youngcc` |
| [Админ-панель](http://localhost:3000/admin) | Логин `admin`, пароль `youngcc` |

Для запуска в локальной сети или с внешним адресом используйте данные из `film-data/local-auth.json`. Переменные окружения `ACCESS_CODE`, `ADMIN_USER` и `ADMIN_PASSWORD` переопределяют данные для входа.

В админ-панели укажите название и описание, выберите MP4 размером до 90 МиБ и нажмите **Загрузить фильм**. Откройте или обновите каталог после входа с кодом зрителя. Фильм хранится в папке `film-data` и остаётся в каталоге после перезапуска сервера.

### Если сервер не запускается

| Ошибка | Что сделать |
| --- | --- |
| `node: command not found` или «node не является внутренней или внешней командой» | Установите Node.js LTS, откройте новое окно терминала и снова проверьте `node --version`. |
| `Cannot find module … build.mjs` или `ENOENT` при чтении `worker.mjs` | Полностью распакуйте ZIP и откройте терминал именно в папке с `package.json`. |
| `ERR_MODULE_NOT_FOUND` с путём `dist/server/index.js` | Сначала выполните `node build.mjs`, затем `node server.mjs`. |
| PowerShell блокирует запуск `npm.ps1` | Выполните две команды `node` из шага 3. Они обходятся без npm. |
| `EADDRINUSE` | Порт 3000 уже занят. Используйте порт 3001 по инструкции ниже. |
| Браузер пишет, что не удалось подключиться | Проверьте, что окно сервера открыто и в нём есть строка с адресом. Введите адрес с `http://`. Если `localhost` не открывается, попробуйте [http://127.0.0.1:3000](http://127.0.0.1:3000). |

Если порт 3000 занят, после сборки выполните команду для своего терминала и откройте [http://localhost:3001](http://localhost:3001). Админ-панель будет по адресу [http://localhost:3001/admin](http://localhost:3001/admin).

- **Linux или macOS** — `PORT=3001 node server.mjs`
- **Windows, командная строка** — `set "PORT=3001" && node server.mjs`
- **Windows, PowerShell** — `$env:PORT = '3001'; node server.mjs`

## Доступ с другого устройства в той же сети

По умолчанию сайт доступен только на компьютере, где он запущен. Для доступа с телефона или другого компьютера в той же сети узнайте локальный IP компьютера с сервером. В командах ниже замените `192.168.1.50` на этот адрес.

Linux или macOS:

```sh
HOST=0.0.0.0 PUBLIC_ORIGIN=http://192.168.1.50:3000 npm start
```

Windows PowerShell:

```powershell
$env:HOST = '0.0.0.0'
$env:PUBLIC_ORIGIN = 'http://192.168.1.50:3000'
npm start
```

На другом устройстве откройте `http://192.168.1.50:3000` с вашим IP-адресом. Если системный брандмауэр спросит о доступе, разрешите входящие подключения к TCP-порту 3000 для частной сети. Используйте этот режим в доверенной сети, поскольку локальное подключение идёт по HTTP.

## Перенос на другой сервер

Скопируйте исходники и каталог `film-data/`, чтобы сохранить загруженные фильмы и учётные данные. Храните каталог данных вне публичной директории. Запустите `npm start` под менеджером процессов и настройте HTTPS-прокси. Укажите внешний адрес, например `PUBLIC_ORIGIN=https://cinema.example.com`, и разрешите в прокси размер запроса не менее 90 МиБ.

Порт задаётся через `PORT`, путь к каталогу данных — через `FILM_DATA_DIR`. Для переопределения учётных данных можно использовать переменные `ACCESS_CODE`, `ADMIN_USER`, `ADMIN_PASSWORD` и `SESSION_SECRET`.
